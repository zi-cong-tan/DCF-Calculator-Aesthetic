Sensitivity: WACC and terminal growth

Rows move the discount rate, columns move terminal growth. Higher growth adds value only when terminal ROIC is above WACC; below it, growing costs more than it earns, so value falls as growth rises (see step 3).

Built on the DCF template: mid-year discounting, a part-year for the first forecast year, and a terminal value in which reinvestment is growth ÷ return on capital. Banks, brokers and insurers use an excess return model instead: book equity plus the present value of profit above the cost of equity, with the same timing.
